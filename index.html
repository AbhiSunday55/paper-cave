Microphone not working? Read this
  • Allow microphone access when your browser asks — check the mic / lock icon in the address bar if you dismissed it.
  • If Paper_cave is embedded in a frame, the frame may block the microphone. Open the tool in its own browser tab and try again.
  • Chrome, Edge and Safari support live dictation; Firefox currently does not. The button will tell you if your browser is unsupported.
  • Your browser's speech engine may use a vendor cloud service for recognition. Audio files you drop into the other tools are never uploaded — only live dictation uses that engine.
  • Windows/Chrome: set a default input device and check that it is not muted in the system sound settings.
